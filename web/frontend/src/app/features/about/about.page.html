About Cartek

Built like an operations product, not a brochure.

Cartek started as a native iOS login and signup experience using MVVM, a SQLite store, and a singleton API layer. This website continues that architecture on the web: views stay thin, view-models own form state, services talk to the network, and the database sits behind a repository so the persistence engine can change without rewriting the product.

What we value

  • Clear boundaries between UI, state, and data access
  • Lazy-loaded feature routes that scale with the team
  • Guarded operator areas after authentication
  • A demo account that matches the original iOS app

The stack

  • Angular 19 standalone components and signals
  • Express with a layered application core
  • SQLite via a repository port
  • JWT sessions with bcrypt-hashed passwords
